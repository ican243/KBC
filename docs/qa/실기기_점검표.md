# 실제 기기 점검표

서버에서는 화면을 눈으로 확인할 수 없으므로, 실제 기기에서 아래 항목을 확인합니다. (기획안 6장 완료 기준)
문제가 있으면 기기·브라우저·페이지·증상(가능하면 화면 캡처)을 적어 주세요.

## 점검 기기

| 기기 | 브라우저 | 점검자 | 날짜 |
|---|---|---|---|
| 아이폰 | Safari | | |
| 안드로이드 | Chrome / 삼성 인터넷 | | |
| PC (Windows) | Chrome, Edge | | |
| (가능하면) Mac | Safari | | |

## 1. 공통 (모든 페이지)

| 아이폰 | 안드로이드 | PC | 확인 항목 |
|---|---|---|---|
| ☐ | ☐ | ☐ | 글자가 잘리거나 겹치지 않는다 |
| ☐ | ☐ | ☐ | 가로로 밀리는(좌우 스크롤) 화면이 없다 |
| ☐ | ☐ | — | ☰ 메뉴가 열리고 닫히며, 메뉴를 누르면 이동한다 |
| ☐ | ☐ | — | 하단 "사전 상담 신청" 버튼이 내용을 가리지 않는다 |
| — | — | ☐ | 상단 메뉴 5개가 이동하고 현재 메뉴에 밑줄이 있다 |
| ☐ | ☐ | ☐ | 스크롤하면 상단 메뉴가 흰색으로 바뀐다 |
| ☐ | ☐ | ☐ | 브라우저 탭 아이콘(남색 + 빨간 점)이 보인다 |
| ☐ | ☐ | — | 가로 모드로 돌려도 화면이 깨지지 않는다 |
| ☐ | ☐ | — | 휴대폰 글자 크기를 크게 해도 읽을 수 있다 |
| — | — | ☐ | Tab 키만으로 메뉴·버튼·입력칸을 이동할 수 있고 선택 표시가 보인다 |

## 2. 페이지별

| 아이폰 | 안드로이드 | PC | 페이지 | 확인 항목 |
|---|---|---|---|---|
| ☐ | ☐ | ☐ | 홈 | 첫 화면 문구, 세로 방송 화면, 과정 카드 3개, 자세히 보기 링크 |
| ☐ | ☐ | ☐ | 아카데미 소개 | 소개·강사진 탭 이동 |
| ☐ | ☐ | ☐ | 교육과정 | 비교표 (휴대폰은 좌우로 밀어서 보기), 과정 상세 이동 |
| ☐ | ☐ | ☐ | 과정 상세 | "이 과정 상담 신청하기" → 상담 폼에 과정이 선택되어 있음 |
| ☐ | ☐ | ☐ | 강사진 | 카드, 사진(입력한 경우) |
| ☐ | ☐ | ☐ | 진로 연계 | 절차 3단계 |
| ☐ | ☐ | ☐ | 소식 | 설명회, 공지 목록, 공지 본문 |
| ☐ | ☐ | ☐ | 자주 묻는 질문 | 질문을 누르면 답변이 펼쳐짐 |
| ☐ | ☐ | ☐ | 개인정보 처리방침 | 하단 링크로 이동 |
| ☐ | ☐ | ☐ | 없는 주소 | "페이지를 찾을 수 없습니다" 화면과 버튼 |

## 3. 폼 (실제로 제출)

같은 연락처로는 10분에 한 번만 접수됩니다. 여러 번 시험할 때는 연락처를 바꿔 주세요.

| 아이폰 | 안드로이드 | PC | 확인 항목 |
|---|---|---|---|
| ☐ | ☐ | ☐ | 상담 신청: 빈칸으로 제출 → 칸별 빨간 안내, 입력한 내용 유지 |
| ☐ | ☐ | ☐ | 상담 신청: 정상 제출 → 접수번호 화면 |
| ☐ | ☐ | ☐ | "내용 보기"를 누르면 개인정보 안내가 펼쳐짐 |
| ☐ | ☐ | ☐ | 휴대폰 번호 입력 시 숫자 키패드가 뜸 (휴대폰) |
| ☐ | ☐ | ☐ | 협력 제안: 정상 제출 → 접수번호 화면 |
| ☐ | ☐ | ☐ | 알림 메일이 도착함 (접수번호, 가린 이름) |

## 4. 관리자 (PC 권장, 휴대폰도 가능)

| 완료 | 확인 항목 |
|---|---|
| ☐ | 로그인 → OTP 6자리 → 대시보드 |
| ☐ | 방금 넣은 상담·협력 문의가 목록에 보임 |
| ☐ | 상태 변경, 담당자, 메모 → 처리 이력 |
| ☐ | CSV 내려받기 → 엑셀에서 한글이 깨지지 않음 |
| ☐ | 교육과정·강사진·공지·설명회·FAQ 등록/수정 → 홈페이지에 반영 |
| ☐ | 강사 사진 올리기 (휴대폰 사진 그대로) → 똑바로 보임 |
| ☐ | 사이트 설정 저장 → 하단 정보 반영 |
| ☐ | 비밀번호 변경 |
| ☐ | 점검용으로 넣은 문의·콘텐츠 삭제 |
