# 회사에 요청할 정보 목록

공개 전에 회사에서 확정·제공해야 하는 항목입니다. 받는 대로 관리자 화면에 입력하거나 개발에 반영합니다.
기준: 기획안 9장 "운영 측 제공 자료", 8장 공개 문구 승인표 (미제공 자료는 가상 사실로 채우지 않고 "준비 중"으로 표시)

## 1. 사이트 설정 (관리자 화면에서 바로 입력 가능)

| 완료 | 항목 | 설정 이름 | 입력 위치 |
|---|---|---|---|
| ☐ | 운영 주체(법인명) | `operator_name` | 관리자 → 사이트 설정 |
| ☐ | 대표자 | `representative` | 관리자 → 사이트 설정 |
| ☐ | 사업자등록번호 | `business_no` | 관리자 → 사이트 설정 |
| ☐ | 학원 등록번호 | `academy_reg_no` | 관리자 → 사이트 설정 |
| ☐ | 교육장 주소 | `address` | 관리자 → 사이트 설정 |
| ☐ | 대표 연락처 | `phone` | 관리자 → 사이트 설정 |
| ☐ | 대표 이메일 | `email` | 관리자 → 사이트 설정 |
| ☐ | 개인정보 보호책임자 | `privacy_officer` | 관리자 → 사이트 설정 |
| ☐ | 교습비 반환 기준 | `refund_policy` | 관리자 → 사이트 설정 |
| ☐ | 문의 정보 보존 기간 | `inquiry_retention` | 관리자 → 사이트 설정 |
| ☐ | 개인정보 처리방침 시행일 | `privacy_effective_date` | 관리자 → 사이트 설정 |
| ☐ | 개인정보 처리 위탁 (업체·업무) | `privacy_entrusted` | 관리자 → 사이트 설정 |

- 운영 주체(법인명)를 입력하면 하단의 "운영 주체·등록 정보: 준비 중"이 실제 정보로 바뀝니다.
- 대표 연락처는 확정 전에는 비워 둡니다 (기획안 3장: 연락처 확정 전 전화번호 임의 기재 금지).

## 2. 콘텐츠 (관리자 화면에서 입력)

| 완료 | 항목 | 비고 |
|---|---|---|
| ☐ | 과정별 주차 시간표, 교습비, 확정 여부 | 교육과정 → "확정된 과정" 체크 시 교습비 표시 |
| ☐ | 강사 실명·프로필·검증된 경력·사진 + 게시 동의 | 강사진 → "게시 동의" 체크 시 공개 |
| ☐ | 설명회 일정 (일시, 장소) | 설명회 |
| ☐ | 자주 묻는 질문 (수강, 교습비·환불, 연령) | FAQ |
| ☐ | 교습비 반환 기준 | 사이트 설정 → 교습비 반환 기준 (등록 내용과 동일해야 함) |

## 3. 파일·디자인

| 완료 | 항목 | 교체 위치 |
|---|---|---|
| ☐ | 확정 로고 (브랜드 표기 결정자 확인) | 헤더 글자 로고, 공유 이미지, 아이콘 |
| ☐ | 교육장·수업 사진 (촬영 허가, 초상 사용 동의) | 실제 사진 확보 전에는 사용하지 않음 (기획안 6장) |

## 4. 운영·계정

| 완료 | 항목 | 비고 |
|---|---|---|
| ☐ | 도메인, 호스팅(서버) | 12번 도메인 이전의 전제 조건. 도메인·호스팅 계정 소유권은 운영 주체에 귀속 (기획안 6장) |
| ☐ | 새 문의 알림 받을 이메일 | 현재 개발용 개인 메일로 설정 |
| ☐ | 메일 발송 계정 (회사 메일 SMTP) | 현재 개발용 네이버 계정 |
| ☐ | 문의 처리 담당자, 관리자 계정 인원 | 관리자 계정 생성 (각자 2단계 인증) |
| ☐ | 문의 정보 보존 기간 (일 단위) | 자동 파기 기능 준비됨 (현재 꺼짐) |
| ☐ | 관리자 열람 기록 보관 기간 | 현재 1년으로 설정 |
| ☐ | 서버 밖 백업 보관 위치 | 현재 같은 서버에만 자동 백업 (매일, 14일) |

## 5. 승인·검토 (기획안 9장 승인 흐름)

| 완료 | 항목 | 검토자 |
|---|---|---|
| ☐ | 공개 문구 전체 (공개문구_검수표.md) | 사업 책임자 → 법무 |
| ☐ | 개인정보 처리방침·수집 안내 문구 | 법무 |
| ☐ | 진로 연계 문구 (직업소개 신고·등록 요건 해당 여부) | 법무 (기획안 8장) |
| ☐ | 학원 등록·교습과정 신고 상태에 맞는 과정 표기 | 사업·교육 (기획안 7장) |
| ☐ | 최종 공개 승인 | 황재윤 대표 (기획안 최종 컨펌) |
