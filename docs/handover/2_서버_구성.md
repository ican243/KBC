# 2. 서버 구성

## 전체 구조

```
                       방문자 / 관리자 (브라우저)
                                │ HTTPS
                                ▼
                     nginx  (SSL, 보안 헤더, 정적 파일)
                ┌───────────────┴───────────────┐
      공개 홈페이지 주소                     관리자 주소
                │                               │
                ▼                               ▼
     PHP-FPM kbc pool  (/run/php/php8.3-fpm-kbc.sock, www-data)
                │                               │
     user (CodeIgniter4)                 admin (CodeIgniter4)
     DB 계정 kbc_user                     DB 계정 kbc_admin
                └──────────────┬────────────────┘
                               ▼
                       MySQL 8  kbc_db
                               │
          새 문의 알림 ──▶ 네이버 SMTP (465/SSL) ──▶ 담당자 메일
```

- **user 와 admin 은 서로 다른 프로그램**이다. 코드·설정·세션·DB 계정이 모두 따로다.
- 공개 홈페이지는 문의를 **등록만** 할 수 있고, 조회는 관리자만 할 수 있다.

## 폴더

```
/var/www/kbc/
├─ user/                  공개 홈페이지
│  ├─ app/                컨트롤러·화면·모델
│  ├─ public/             웹에 공개되는 폴더 (index.php, css, js, 글꼴, 이미지)
│  │  └─ uploads/instructors/   강사 사진 (git 제외, 백업 대상)
│  ├─ writable/           로그·캐시·세션 (www-data 쓰기)
│  └─ .env                설정 (git 제외, 권한 640)
├─ admin/                 관리자 (같은 구조)
│  └─ app/Database/Migrations/  DB 테이블 정의 (마이그레이션은 여기서만 관리)
├─ database/schema.sql    DB 구조 참고용
├─ scripts/               백업·로그 정리·공유 이미지 생성 스크립트
└─ docs/                  서버 설정 원본, 점검 문서, 인수인계 문서
```

## 서버 쪽 파일

| 서버 위치 | 원본 (저장소) | 내용 |
|---|---|---|
| `/etc/nginx/snippets/kbc-subpath.conf` | `docs/nginx/kbc-subpath.conf` | 개발 기간 하위경로(/kbc/, /kbc/admin/) 설정 |
| `/etc/nginx/sites-available/kbc` | 1번 문서 8) | 도메인 연결 후 설정 |
| `/etc/php/8.3/fpm/pool.d/kbc.conf` | `docs/php-fpm/kbc.conf` | KBC 전용 PHP 실행 공간 |
| `/etc/cron.d/kbc` | `docs/ops/cron.kbc` | 자동 백업·로그 정리 예약 |
| `/usr/local/sbin/kbc-backup` | `scripts/backup.sh` | 자동 백업 |
| `/usr/local/sbin/kbc-cleanup-logs` | `scripts/cleanup-logs.sh` | 로그 정리 |
| `/var/www/backups/kbc_auto/` | - | 자동 백업 파일 (14일 보관) |

## DB

DB 이름 `kbc_db`, 문자셋 utf8mb4.

| 테이블 | 내용 | 공개 홈페이지(kbc_user) 권한 |
|---|---|---|
| admins | 관리자 계정 (비밀번호 해시, 2단계 인증) | 없음 |
| courses | 교육과정 | 조회 |
| instructors | 강사진 | 조회 |
| notices | 공지 | 조회 |
| events | 설명회 일정 | 조회 |
| faqs | 자주 묻는 질문 | 조회 |
| site_settings | 사이트 설정 18개 | 조회 |
| consult_inquiries | 교육 상담 신청 | 등록 |
| partner_inquiries | 기관 협력 제안 | 등록 |
| inquiry_memos | 문의 처리 이력 | 없음 |
| notification_logs | 알림 메일 발송 기록 | 등록 |
| page_views | 날짜·페이지별 조회수 (개인정보 없음) | 조회·등록·수정 |
| migrations | 적용된 마이그레이션 기록 | 없음 |

| DB 계정 | 사용처 | 권한 |
|---|---|---|
| kbc_user | user/.env | 위 표의 권한만 |
| kbc_admin | admin/.env | kbc_db 조회·등록·수정·삭제 |
| kbc_migrate | admin/.env (migrate 그룹) | kbc_db 전체 — 테이블 변경 때만 |
| kbc | 개발 기간 DB 관리 프로그램(HeidiSQL) 접속용 | kbc_db 전체 — **인수인계 때 삭제 또는 비밀번호 교체** |

## 보안 설정 요약

| 구분 | 내용 | 위치 |
|---|---|---|
| 전송 | HTTPS, 쿠키 secure | nginx, `.env` |
| 화면 | 우리 서버 스크립트만 실행(CSP), 다른 사이트에 끼워 넣기 차단 | nginx |
| 폼 | CSRF 토큰, 숨김 칸·3초 검사(봇), IP 10분 3회, 같은 연락처 10분 재접수 제한 | `user/app/Libraries/SpamGuard.php` |
| 관리자 로그인 | 비밀번호 + OTP 2단계 인증, 5회 실패 시 10분 잠금 | `admin/app/Controllers/Auth.php` |
| 관리자 권한 | 대표 관리자 / 담당자, 매 요청 DB 확인 | `admin/app/Filters/AdminAuth.php` |
| OTP 비밀키 | `encryption.key` 로 암호화 저장, 복구 코드는 해시 | `admin/app/Libraries/TwoFactor.php` |
| 업로드 | 이미지 내용 검사, 다시 저장(위치정보 제거), 무작위 이름 | `admin/app/Libraries/ImageUpload.php` |
| 파일 실행 | `index.php` 외 PHP 실행 차단, 숨김 파일 차단 | nginx |
| PHP | KBC 폴더 밖 접근 차단(open_basedir) | PHP-FPM pool |
| 개인정보 열람 | 상세 보기·CSV·삭제 기록 (1년 보관) | `admin/writable/logs/audit-날짜.log` |
| 알림 메일 | 이름 가림(홍*동), 연락처·내용 미포함 | `user/app/Libraries/InquiryNotifier.php` |

## 요청 흐름 (상담 신청 예)

```
폼 제출 → CSRF 확인 → 봇 검사 → 입력값 검사 → IP 제한 → 연락처 중복 확인
→ 접수번호 발급(C+날짜+5자리) → DB 저장 → 완료 화면으로 이동(새로고침해도 중복 접수 안 됨)
→ 화면 전송 후 알림 메일 발송 → 결과를 notification_logs 에 기록
```
