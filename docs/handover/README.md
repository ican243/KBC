# KBC아카데미 홈페이지 인수인계 문서

홈페이지를 회사 서버·도메인으로 옮기고 운영하는 데 필요한 문서 모음이다.
**비밀번호는 어떤 문서에도 적지 않는다.** 계정 정보는 3번 양식을 채워 따로 전달한다.

| 순서 | 문서 | 읽는 사람 | 언제 |
|---|---|---|---|
| 1 | [설치 가이드](1_설치_가이드.md) | 개발자·호스팅 담당 | 새 서버에 처음 설치할 때 |
| 2 | [서버 구성](2_서버_구성.md) | 개발자 | 구조를 이해하거나 문제를 찾을 때 |
| 3 | [계정 목록 양식](3_계정_목록_양식.md) | 회사 책임자 | 인수인계할 때 (채워서 별도 전달) |
| 4 | [백업·복구 절차](4_백업_복구_절차.md) | 개발자 | 정기 점검, 서버 고장, 서버 이전 |
| 5 | [관리자 사용 설명서](5_관리자_사용_설명서.md) | 회사 담당자 | 매일 문의 처리·콘텐츠 입력 |
| 6 | [도메인 이전 체크리스트](6_도메인_이전_체크리스트.md) | 개발자 | 회사 도메인 구입 후 공개 전환 |

함께 보는 문서

- 저장소 맨 위 `README.md` : 기능·주소·파일 위치 요약
- `docs/qa/` : 공개 전 점검 결과, 실기기 점검표, 공개 문구 검수표, 채워야 할 정보
- `user/.env.example`, `admin/.env.example` : 설정 파일 견본

문서 안의 **"결정 필요"** 는 회사가 정해야 하는 항목이다.
