# 5. 관리자 사용 설명서

홈페이지에 들어온 문의를 처리하고, 교육과정·강사·공지 같은 내용을 바꾸는 방법이다.
관리자 주소: ______________________ (도메인 연결 후 기입)

---

## 1. 처음 로그인하기

1. 대표 관리자에게 **아이디와 임시 비밀번호**를 받는다.
2. 관리자 주소에서 아이디·임시 비밀번호로 로그인한다.
3. **비밀번호 변경** 화면이 나온다. "현재 비밀번호"에 임시 비밀번호, 새 비밀번호(10자 이상)를 두 번 입력한다.
4. **2단계 인증 설정** 화면이 나온다.
   - 휴대폰에 OTP 앱을 설치한다. (Google Authenticator, Microsoft Authenticator 등 무료 앱)
   - 앱에서 화면의 QR 코드를 찍고, 앱에 나온 6자리 숫자를 입력한다.
5. **복구 코드 8개**가 한 번만 나온다. 종이에 적거나 안전한 곳에 보관한다. (휴대폰을 잃어버렸을 때 사용)

다음부터는 **아이디·비밀번호 → 휴대폰 OTP 앱의 6자리 숫자** 순서로 로그인한다.

- 비밀번호나 OTP 를 5번 틀리면 10분 동안 로그인할 수 없다.
- 공용 PC 에서는 사용 후 반드시 오른쪽 위 **로그아웃**을 누른다.

## 2. 역할

| 할 수 있는 일 | 대표 관리자 | 담당자 |
|---|---|---|
| 문의 보기·처리, 콘텐츠 수정, 통계, 알림 기록, 내 계정 | O | O |
| 문의 엑셀(CSV) 내려받기, 문의 삭제, 사이트 설정, 관리자 계정 관리 | O | X |

## 3. 매일 할 일: 문의 처리

**대시보드**에서 새 문의 수, 오늘 접수, 알림 메일 실패를 확인한다.
새 문의가 들어오면 알림 받는 메일로 접수번호와 가린 이름(홍*동)이 온다. 연락처와 내용은 관리자 화면에서만 볼 수 있다.

### 상담 문의 / 협력 제안

1. 메뉴에서 **상담 문의**(수강 상담) 또는 **협력 제안**(교육장·강사·채용 협력)을 누른다.
2. 목록에서 문의를 눌러 상세를 연다.
3. 연락한 뒤 아래 **처리하기** 칸에서 상태·담당자·메모를 입력하고 저장한다. 저장할 때마다 처리 이력이 쌓인다.

| 상태 | 뜻 |
|---|---|
| 신규 | 아직 연락 안 함 |
| 연락 | 연락함 (통화·문자), 상담 진행 중 |
| 상담완료 | 상담 끝 |
| 보류 | 연락 안 됨, 나중에 다시 등 |

- 목록 위에서 상태·과정·기간·유입 경로로 거르거나, 이름·연락처·접수번호로 찾을 수 있다.
- 문의한 사람이 접수번호를 알려주면 검색창에 넣어 찾는다.
- **삭제**(대표 관리자)는 목록에서만 사라지고 기록은 남는다. 장난·중복 문의에만 사용한다.
- **CSV 내려받기**(대표 관리자)는 지금 거른 목록을 엑셀 파일로 받는다. 받은 파일은 개인정보이므로 사용 후 지운다.

> 개인정보 주의: 문의자의 연락처·내용을 개인 메신저나 공용 폴더에 옮기지 않는다. 상세 보기·내려받기·삭제는 누가 언제 했는지 기록된다.

## 4. 홈페이지 내용 바꾸기

모든 메뉴에 **공개** 체크가 있다. 체크를 끄면 홈페이지에서 바로 사라진다(삭제 아님). 순서 숫자가 작을수록 앞에 나온다.

### 교육과정
- 시간표·교습비가 정해지기 전에는 **"확정된 과정"을 체크하지 않는다.** 홈페이지에 "시간표·교습비 확정 전"으로 나오고 교습비는 숨겨진다.
- 확정되면 교습비 안내를 입력하고 "확정된 과정"을 체크한다.
- "주소용 이름"은 과정 페이지 주소(예: `/courses/personal`)에 쓰인다. 공개 후에는 바꾸지 않는다. (공유된 링크가 깨짐)
- 과정은 문의 기록과 연결되어 있어 삭제할 수 없다. 운영하지 않으면 공개를 끈다.

### 강사진
- 분야·교육 내용만 입력하면 홈페이지에 이름·사진 없이 분야 카드로 나온다.
- 실명·사진·프로필·경력은 **강사 본인에게 게시 동의를 받은 뒤** "게시 동의를 받았습니다"를 체크해야 홈페이지에 나온다.
- 경력은 증빙(자격증, 방송 기록 등)으로 확인한 내용만 적는다.
- 사진: JPG·PNG·WEBP, 5MB 이하. 자동으로 크기를 줄이고 촬영 위치 정보를 지운다.

### 공지
- 게시일이 지나야 홈페이지에 나온다. 미래 날짜로 적으면 그날부터 자동 공개된다(예약 게시).

### 설명회
- 일시가 지난 설명회는 홈페이지에서 자동으로 빠진다.

### FAQ
- 분류별로 묶여 나온다. 같은 분류 이름을 똑같이 적는다.

## 5. 사이트 설정 (대표 관리자)

비워 둔 항목은 홈페이지에 나오지 않거나 "준비 중"으로 나온다. 바꾼 항목만 저장된다.

| 묶음 | 항목 | 어디에 나오나 |
|---|---|---|
| 안내 문구 | 브랜드명, 현재 운영 상태, 개강 안내, 교습비·개강일 안내, 진로 연계 안내 | 홈·교육과정·진로 연계 화면 |
| 운영 정보 | 운영 주체(법인명), 대표자, 사업자등록번호, 학원 등록번호, 교육장 주소, 대표 연락처, 대표 이메일 | 모든 화면 하단 |
| | 교습비 반환 기준 | 교육과정 화면 (비우면 숨김) |
| 개인정보 | 보호책임자, 문의 정보 보존 기간, 처리 위탁 업체, 처리방침 시행일 | 개인정보 처리방침 화면 |
| 알림 | 새 문의 알림 받을 이메일 | 알림 메일 받는 주소 |

- 학원 등록번호·사업자등록번호는 **등록증을 받은 뒤에만** 입력한다.
- 개인정보 처리방침 시행일은 법무 검토가 끝난 날짜로 입력한다. 비어 있으면 "확정 전 초안"으로 표시된다.

## 6. 통계

**통계** 메뉴에서 기간을 골라 본다.

| 항목 | 뜻 |
|---|---|
| 상담 접수 / 협력 접수 | 기간 안에 들어온 문의 수 (삭제 제외) |
| 상담완료 비율 | 상담 접수 중 "상담완료" 상태 비율 |
| 과정 페이지 → 상담 전환 | 과정 상세 화면에서 신청한 상담 ÷ 과정 상세 조회수 |
| 유입 경로 | 네이버 검색, 인스타그램 등 어디서 들어왔는지 |
| 신청 화면 | 홈 하단 / 상담 문의 화면 / 과정 상세 중 어디서 신청했는지 |
| 많이 본 페이지 | 페이지별 조회수 (방문자 수가 아니라 화면이 열린 횟수) |

광고·게시물 링크 끝에 `?utm_source=이름` 을 붙이면 유입 경로에 나온다. 예) `?utm_source=instagram` → "인스타그램 (링크)"

## 7. 관리자 계정 관리 (대표 관리자)

**관리자 계정** 메뉴

| 하고 싶은 일 | 방법 |
|---|---|
| 직원 계정 만들기 | **+ 계정 추가** → 아이디·이름·역할 → 저장 → **임시 비밀번호가 한 번만 나옴** → 본인에게 직접 전달 |
| 비밀번호를 잊었을 때 / 잠겼을 때 | 해당 계정 **관리** → **임시 비밀번호 발급** (잠금도 풀림) |
| 휴대폰을 바꿨거나 잃어버렸을 때 | 해당 계정 **관리** → **2단계 인증 초기화** → 본인이 다음 로그인 때 다시 설정 |
| 퇴사자 | 해당 계정 **관리** → **사용 중지** (삭제 대신. 처리 기록의 담당자 이름은 유지) |

- 자기 자신과 마지막 대표 관리자는 중지·강등할 수 없다. 대표 관리자는 **2명 이상** 두는 것을 권장한다.

## 8. 휴대폰을 잃어버렸을 때

1. **복구 코드**가 있으면: 로그인 → OTP 입력 칸에 복구 코드 입력 → **내 계정**에서 상태 확인 후, 다른 대표 관리자에게 2단계 인증 초기화를 요청해 새 휴대폰으로 다시 설정한다. (복구 코드는 한 번 쓰면 사라진다)
2. 복구 코드도 없으면: 다른 대표 관리자에게 **2단계 인증 초기화**를 요청한다.
3. 대표 관리자가 한 명뿐이고 그 사람이 잃어버렸다면: 서버 담당자에게 요청한다. (서버 명령 `php spark admin:reset-2fa 아이디`)

## 9. 알림 기록

**알림 기록** 메뉴에서 새 문의 알림 메일이 잘 나갔는지 본다. "실패"가 있으면 문의 자체는 정상 접수된 것이니 목록에서 확인하고, 계속 실패하면 서버 담당자에게 알린다. (메일 계정 비밀번호 변경 등이 원인)

## 10. 홈페이지에 쓰면 안 되는 표현

공지·FAQ·과정 설명·설정 문구를 쓸 때 지킨다. (학원 광고 관련 법령과 기획안 기준)

| 쓰지 않는다 | 대신 |
|---|---|
| 취업 보장, 수료 즉시 취업, 100% 취업 | 진로 연계 기회 안내, 설명회·면접 기회 연계 |
| 월 ○○만원 수익, 억대 연봉 등 소득 금액 | 소득 표현 없이 교육 내용 중심 |
| 엑셀방송 | 협업형 라이브 방송 |
| 취업 알선, 일자리 소개 | 협력 기관 연계 (직업소개 관련 신고·등록 검토 전) |
| 인터넷에서 받은 사진, 확인되지 않은 경력 | 직접 찍은 사진, 증빙 확인한 경력 |
| 정해지지 않은 교습비·일정 | "준비 중", "확정 전" |

강사 실명·사진은 본인 동의 후에만 올린다.
