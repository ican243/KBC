# 3. 계정 목록 양식

> **이 양식에는 비밀번호를 적지 않는다.**
> 비밀번호는 문서·메일·메신저 대화에 남기지 말고, 비밀번호 관리 프로그램 공유 또는 직접 전달한다.
> 인수인계가 끝나면 아래 **모든 비밀번호를 회사가 새로 바꾼다.** (6번 체크리스트)

작성일: ____________  작성자: ____________  인수자: ____________
